🏗️ System Architecture

RISC Core (5-Stage Pipeline)

  • IF - Instruction Fetch from L1 I-Cache
  • ID - Instruction Decode & Register Read
  • EX - Execute (ALU operations)
  • MEM - Memory Access via L1 D-Cache
  • WB - Write Back to Register File

Components: PC, IR, Register File (8 regs), ALU, Control Unit, L1 Caches

CISC Core (Microcoded)

  • Complex Instruction Decoder - Interprets ADD4 opcode
  • Micro-operation Sequencer (FSM) - 13+ states for ADD4
  • Temporary Registers - 4 temp regs for intermediate results
  • Dual L1 D-Caches - High-throughput data access

Key Feature: One complex instruction performs entire operation

Hybrid Core (INNOVATION) 🏆

  • Instruction Translator - Converts CISC to optimized RISC micro-ops (0 cycles!)
  • Micro-op Fusion Engine - Combines operations (LOAD_DUAL, LOAD_ADD)
  • Optimized RISC Execution Core - Fast micro-op execution
  • Micro-op Queue - Buffers translated operations

Key Innovation: Accepts CISC instructions but executes with RISC efficiency

Memory Hierarchy

  • L1 I-Cache - 4KB, private to each core, 1-cycle access
  • L1 D-Cache - 4KB, private to each core, 1-cycle access
  • L2 Cache (Shared) - 256KB, 8-way set-associative, 8-cycle access
  • System Interconnect - Bus connecting cores and caches
  • Main Memory - 256 words, 16-bit, 50-cycle latency

🔬 Technical Specifications

System Parameters

  • Word Size: 16-bit
  • Memory Size: 256 words (0x00-0xFF)
  • Register Count: 8 (R0-R7, R0 hardwired to 0)
  • ALU Operations: ADD, SUB
  • Addressing: 8-bit direct addressing

Benchmark Program

Input: M[0]=5, M[1]=10, M[2]=15, M[3]=20
Operation: SUM = M[0] + M[1] + M[2] + M[3]
Expected Output: M[4] = 50

Instruction Sets

RISC ISA: LOAD, STORE, ADD, SUB, JUMP, HALT (6 instructions)

CISC ISA: ADD4, HALT (2 instructions)

Hybrid ISA: Accepts CISC, translates to RISC micro-ops
