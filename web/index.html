ℹ️ About This Project

Benchmark Program

Input: M[0]=5, M[1]=10, M[2]=15, M[3]=20
Operation: SUM = M[0] + M[1] + M[2] + M[3]
Output: M[4] = 50

Architecture Descriptions

RISC: Reduced Instruction Set Computer - Simple instructions, one operation per cycle, more instructions needed

CISC: Complex Instruction Set Computer - One complex instruction (ADD4) does all operations, but takes many cycles

Hybrid: Accepts CISC instructions, translates to RISC micro-operations internally - Best performance!

How to Use

  1. Select an architecture (RISC, CISC, or Hybrid)
  2. Click RUN to execute the benchmark program
  3. Or click STEP to advance one clock cycle at a time
  4. Watch registers and memory update in real-time
  5. View performance metrics on the right
  6. Click "Performance Comparison" to see all results side-by-side

Modify & Re-run

Edit the memory values (M[0] through M[3]) and click "Load Values", then run again to see different results!
